# Learn SQL in 14 Days

Welcome to **Learn SQL in 14 Days**, a free, hands-on SQL learning series by Ley Sylvester.

This series introduces SQL fundamentals through practical examples using a sample store database. Whether you're completely new to SQL or looking to refresh your skills, you can follow along with the videos and practice the queries yourself.

## Sample Database

The series uses a sample store database with six related tables:

- **CATEGORIES:** Product categories
- **PRODUCTS:** Product details, prices, and inventory
- **CUSTOMERS:** Customer information
- **ADDRESSES:** Customer addresses
- **ORDERS:** Customer orders and shipping information
- **ORDER_ITEMS:** Products purchased in each order

The database includes sample records designed to help you practice filtering, joins, aggregate functions, subqueries, and data modifications.

## Getting Started

1. Set up an Oracle AI Database 26ai environment.
2. [Download the SQL setup script](learn_sql_14_days_setup.sql).
3. Connect to your database using SQL*Plus or another Oracle SQL-compatible tool.
4. Run the setup script to create the tables and insert the sample data.
5. Follow along with the video lessons and practice the SQL queries.

**Important:** The setup script drops and recreates the six sample tables. Run it only in a dedicated practice schema where you do not need to preserve existing data.
